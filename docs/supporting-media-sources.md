## Usage rules applied

- Video is **embedded only** (click-to-load facade), never downloaded or re-uploaded.
- Each video carries a "Watch on source platform" link.
- Reference rows are **outbound links only**; their images are not copied into the project.
- Image reuse from the Lusaka Times / ZANIS report requires publisher permission (links only here).
